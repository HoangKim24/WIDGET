# App Icon - Lịch Tuần

Tài nguyên biểu tượng ứng dụng (App Icon) chính thức:

- **Thiết kế:** Flat line-art phong cách hiện đại (Lịch tuần + Huy hiệu tích xanh hoàn thành)
- **Đã tích hợp trong Asset Catalog:** `Shared/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`
- **Tương thích:** iOS (Asset Catalog 1024x1024) và Android (Adaptive Icon)
